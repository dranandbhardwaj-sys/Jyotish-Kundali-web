# Jyotish Kundali (Web)

Free Vedic astrology website: janam kundali, navamsa, mahadasha, gochar, vivah milan, panchang, muhurta, rashifal and calculators, in Hindi/Hinglish.

## Run

Static site. Open `index.html` or deploy the folder to GitHub Pages / any static host.

Includes `privacy-policy.html`, `disclaimer.html`, `about.html`, `sitemap.xml` and `robots.txt`.
